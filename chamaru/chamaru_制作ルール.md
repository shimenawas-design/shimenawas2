# 制作ルール（付録）

> 統合マスター_YYMMDD.md（インデックス）から分割。制作フロー・Suno選定ロジック・40Hz重ね方・量産マトリクス・遵守事項など、比較的変わらない参照ルール類。

## 制作フロー

1. Suno生成 → WAV保存（1プロンプトから4曲出る）
2. **4バリエーションの分析**（t1/t2/t3・rng・必要なら hf_ratio）
3. **状態別の選定・組み立て**（下記）→ 目標尺ちょうどのWAVにする
4. **（ブレインフォグのみ）40Hz重ね** ← 音量統一の**前**
5. 音量統一 -20dBFS（`normalize_all.py`。ピーク-1.5dBキャップ、可逆ゲインのみ）
6. Gemini で背景生成 → ✦透かし除去 → 茶丸の透過PNGを合成（`generic_prep.py`）
7. ffmpeg zoompan 8%スロームズームで動画化
8. サムネ作成

### 尺の対応

| 状態 | 尺 | ffmpeg `-t` | zoompan `d=` | zoompan `z=zoom+` | `afade` out `st=` | `-stream_loop` |
|---|---|---|---|---|---|---|
| 目覚め | 30分 | 1800 | 43200 | 0.0000018519 | 1785 | **なし** |
| 集中 / ブレインフォグ / 画面疲れ | 60分 | 3600 | 86400 | 0.00000092593 | 3585 | あり |
| リセット / 安眠 | 90分 | 5400 | 129600 | 0.00000061728 | 5385 | あり |

> ⚠️ **目覚め回では `-stream_loop -1` を付けない。** 音声を無限ループさせると一方向の設計が壊れる。目覚めの音源は最初からちょうど尺で作る。
> ⚠️ `zoompan` の増分は「8%ズームを尺いっぱいで使い切る」値（0.08 ÷ フレーム数）。尺が半分なら増分は倍になる。

### スロームズーム動画（60分の例）

```bash
ffmpeg -i bg_with_chamaru.png -stream_loop -1 -i seam.wav -t 3600 \
  -vf "crop=2731:1536,zoompan=z=zoom+0.00000092593:d=86400:x=iw/2-(iw/zoom/2):y=ih/2-(ih/zoom/2):s=1920x1080:fps=24,format=yuv420p" \
  -r 24 -map 0:v:0 -map 1:a:0 -c:v libx264 -preset veryfast -crf 21 -pix_fmt yuv420p \
  -c:a aac -b:a 192k -af "afade=t=in:st=0:d=3,afade=t=out:st=3585:d=15" -movflags +faststart out.mp4
```

音声だけ差し替える場合は `-c:v copy` で再mux（映像無劣化）。

### 崩れ防止の鉄則

- **茶丸のピクセルは絶対に加工しない**（背景・光・文字だけ処理する）
- **背景プロンプトから「中央手前を空ける」指定を消さない**
- **光は全カット左固定**（茶丸の陰影が左採光のため）
- `workshop` など開いた語は使わない

## Suno 4バリエーションの組み合わせ手法

Sunoは1プロンプトから4曲（main, _1, _2, _3）出る。1曲をループするのではなく、4曲を分析して狙った曲調になるよう組み合わせる。

### 分析する指標

| 指標 | 定義 |
|---|---|
| **t1 / t2 / t3** | 10秒窓のRMS(dB)を計算し、曲全体を3等分してそれぞれの平均 |
| **rng** | RMS(dB)系列の 95パーセンタイル − 5パーセンタイル（小さいほど平坦） |
| **hf_ratio** | 2000Hz以上のFFTエネルギー比率（画面疲れ用） |

### 状態ごとの選定ロジック

| 状態 | ロジック |
|---|---|
| 集中・リセット | rng最小（最も平坦）順に**4曲すべて**採用、順に並べてクロスフェード連結 |
| 安眠 | **終盤(t3)が最も静かになる曲を最後に**配置 |
| 目覚め | **2曲のみ**。t1最小の曲を前半にループ、t3最大の曲を後半に**1回だけ**繋げる。**全体を通しでループしない** |
| ブレインフォグ | rng最小の**2曲のみ**（均一密度を最優先。40Hzを重ねる下地として重要） |
| 画面疲れ | hf_ratio最小の**2曲のみ**＋6.5kHz程度のローパスを軽くかける |

### つなぎ方

- 異なる曲同士のクロスフェード：**8秒**
- ループの継ぎ目：**6秒**
- 目標尺まで届かない場合は、継ぎ目を作ってから通し全体をループ延長
- Sunoの4テイクは音量がばらつくことがある。組み立て前にRMSを揃えておくと継ぎ目に段差が出ない

### 実績値の目安（9月13話・52本の分析より）

- **前半t1**: -16〜-12dB程度
- **rng**: 平坦なもので4〜6dB、起伏があるもので8〜12dB
- **hf_ratio**: 低いもので0.02程度、高いもので0.10程度

## 40Hz バイノーラルの重ね方（17・23・28・29）

**Sunoでは作れない。** バイノーラルビートは左右の周波数差で成立するため、生成AIでは精度が出ない。ffmpegで後付けする。検証済み（L=200Hz / R=240Hz → 差分40Hz をFFTで実測確認）。

```bash
ffmpeg -y -i suno.wav \
  -f lavfi -i "sine=frequency=200:sample_rate=48000" \
  -f lavfi -i "sine=frequency=240:sample_rate=48000" \
  -filter_complex "\
[0:a]aresample=48000,pan=mono|c0=c0[ml];\
[0:a]aresample=48000,pan=mono|c0=c1[mr];\
[1:a]volume=0.05[tl];[2:a]volume=0.05[tr];\
[ml][tl]amix=inputs=2:duration=first:weights=1 1,volume=2[L];\
[mr][tr]amix=inputs=2:duration=first:weights=1 1,volume=2[R];\
[L][R]join=inputs=2:channel_layout=stereo[out]" \
  -map "[out]" -c:a pcm_s16le out.wav
```

**ハマりどころ**：`amix` でいきなり混ぜると**ステレオがダウンミックスされ左右分離が壊れる**。左右チャンネルを個別に分解 → 個別に混ぜる → 最後に `join` で戻すのが正解。

- トーン音量は `0.05`（小さめ）。上げすぎると音楽を邪魔する
- **ヘッドホン推奨を概要欄に明記**（スピーカーでは左右が空中で混ざり構造が成立しない）
- 40Hz重ねは**音量統一（-20dBFS）の前**に行う

> **28・29は自然音（水音・蝉）を主体テクスチャにしているため、広帯域の持続音が40Hzトーンを自然に隠す。** 静寂の多い曲だと `0.05` でも40Hzが浮いて聴こえるが、この2本は下地として理想的。

## 量産マトリクス

茶丸は固定。変えるのは **状態 × 季節 × 舞台 × 主役楽器 × 自然音** の5軸。

- **状態**（6）：集中 / リセット / 安眠 / 目覚め / ブレインフォグ / 画面疲れ
- **季節**：桜 / 青竹 / 紅葉 / 雪（月替わり）
- **舞台**（5）：茶室 / 縁側 / 庭 / 窓辺 / 囲炉裏端
- **主役楽器**（5）：箏 / 尺八 / ピアノ / 鈴 / 雨音
- **自然音**（5）：雨 / 小川 / 鳥 / 風 / 火

**週の頭にバッチ処理する**（背景をまとめて生成 → 合成 → Suno をまとめて生成）。1本ずつ作らない。

## 遵守事項

### YouTube（量産型 / inauthentic content 対策）

- アップロード時に **AI開示を必ず設定**（未設定は警告 → 収益停止 → YPP除外の対象）
- 静止画＋曲だけにしない。動き・編集・構成の差を入れる
- **同じ曲のピッチ/速度違いはNG**。毎回本当に別の曲を作る
- 説明文は毎回書き下ろす（署名ブロック以外は使い回さない）
- **同型を一気に大量投稿しない。判定はチャンネル単位**

### 薬機法（医薬品医療機器等法）

| NG | OK |
|---|---|
| 改善する / 解消する / 治る / 効く / クリアになる | 〜の時に / 〜のための / 〜に寄り添う（状態・行為表現） |
| 40Hzで脳がクリアになります | 40Hz帯の低い持続音を重ねた設計です |

**英語圏も同じ考え方**

| NG | OK |
|---|---|
| Cure / Heal / Fix / Clears brain fog | **For** foggy mornings / **When** your head feels heavy |
| Boosts focus / Improves concentration | **For** quiet focus / **Designed for** long work sessions |
| Relieves eye strain | **Rest** your eyes / **Screen break** |

- 「ブレインフォグ」はタイトルに常用せず、**説明文とタグに置く**（月1〜2本の専用回でのみ正面から使う）
- **「暑さで頭が回らない」は使わない。** 熱中症の初期症状と重なり医療寄りに読まれるリスクがある。29は「暑さで頭が重くなる午後に」という時間帯＋状態の記述に留めている
- **`ガンマ波` / `gamma wave` はタグにも入れない**
