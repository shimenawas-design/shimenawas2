## ローカライズ（日英の出し分け）

**各話別ファイルはタイトル・概要を日英で分離して記載している。** YouTubeは言語ごとにタイトル・説明文を出し分けられるため、1本のタイトルに日英を併記する必要はない。併記をやめると**それぞれ100文字をフルに使える**。

### 設定手順

1. YouTube Studio → 左メニュー **「字幕」**
2. 対象動画を選択 → **元の言語（日本語）を設定**して「確認」
   - ここが前提条件。元の言語が未設定だと翻訳を追加できない
3. **「言語を追加」** → 英語
4. 英語の行の **「タイトルと説明」→「追加」**
5. 左に日本語原文が出るので、右に英語版を入力 → **「公開」**

### チャンネル自体の翻訳

YouTube Studio →「カスタマイズ」→「基本情報」→「チャンネル名と説明の翻訳」→「＋言語を追加」

> 英語のサムネ・タイトルで流入させても、チャンネルが日本語だけだと離脱する。動画のローカライズとセットで設定すること。

### 切り替わる条件

視聴者の**国や地域ではなく、YouTubeのアプリ／ブラウザの言語設定**で決まる。検証は自分のYouTube言語設定を英語に切り替えて確認する。

### ローカライズできないもの

| 項目 | 可否 |
|---|---|
| タイトル | ✅ |
| 説明文 | ✅ |
| **タグ** | ❌ 全言語共通で1セット |
| **サムネイル** | ❌ 1枚で両言語に対応させる必要がある |

## タグ設計ルール

**共通2 ＋ 状態別3〜4 ＋ 個別5〜6** の3層で組む。10〜12語。500文字上限に対して十分余裕がある。

### ① 共通（全話）
```
和風BGM, japanese ambient
```

### ② 状態別（固定）

| 状態 | 日本語 | 英語 |
|---|---|---|
| 集中 | 作業用BGM, 集中BGM, 勉強用BGM／仕事用BGM | study music, focus music／work music |
| リセット | 休息BGM, リラックスBGM, 切り替え | relaxing music |
| 安眠 | 睡眠用BGM, 安眠BGM, 寝る前BGM, 入眠 | sleep music, night ambient |
| 目覚め | モーニングBGM, 目覚め, 朝活 | morning music, wake up music, gentle morning |
| ブレインフォグ | ブレインフォグ, 40Hz, バイノーラルビート | brain fog, binaural beats, 40hz binaural |
| 画面疲れ | 休息BGM, デジタルデトックス, 目の休息 | screen break, digital detox, eye rest |

### ③ 個別（可変）
主役楽器 ＋ 自然音 ＋ 季節（`夏BGM` / `初秋` / `紅葉`）を、**その回に実際に入っている音だけ**書く。

### 禁止事項
- **他状態のタグを混ぜない**（例：リセット回に `作業用BGM`）。状態別の流入データが判別できなくなる
- **`BGM` 単体・`癒し` 単体などの汎用語を入れない**（ハッシュタグ側には残してよい）
- **指示文をタグにしない**（例：`headphones recommended`）
- **入っていない楽器・音を書かない**

### `ガンマ波` / `gamma wave` は使わない

`40Hz`（周波数の事実表記）と違い、脳への作用を含意する語。薬機法ルールに照らしてグレーなため、英語圏で一般的なタグだが採用しない。
