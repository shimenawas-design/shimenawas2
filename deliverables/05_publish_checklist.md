# ⑤ 1本ごとの公開チェックリスト

まとめて出さない。**1本ずつ**公開し、冒頭の維持率を確認してから次へ。

## 制作
- [ ] Suno で4〜6トラック生成（完成版プロンプト＝末尾に冒頭指定を連結済みを使用）
- [ ] 一番気持ちいい部分を **0:00** に配置した
- [ ] 頭に無音・環境音・フェードインが**ない**（0秒からフル音量でメロディ）
- [ ] 音量が他のBGMチャンネルと**同等**（小さくない）
- [ ] ループで**1時間**に組んだ（集客側は1時間。2時間は幻想側の役割）

## サムネ
- [ ] **人物なし**
- [ ] **左に文字余白**あり
- [ ] **灰青 × 暖色**の対比
- [ ] 書体は**太めのゴシック体**（明朝は幻想側専用なので使わない）
- [ ] 題材は**実在の和の情景のみ**（幻想は入れない）

## メタデータ
- [ ] タイトル先頭が「**和風BGM**」
- [ ] タイトルは `04_titles.md` からコピペ
- [ ] 概要欄は `02_youtube_descriptions.md` のテンプレを使用
- [ ] 概要欄に**幻想和風プレイリストへの導線**を入れた（`{{幻想プレイリストURL}}` 置換済み）
- [ ] 尺は1時間

## 公開後の確認（1点だけ）
- [ ] 維持率グラフの**冒頭が垂直落下していない**
  - 目標：「0:00で高く、なだらかに減衰」の形
  - NG例：京の茶屋＝開始数秒で30%台まで落下
- [ ] 冒頭の崖が直っているか？ → 直っていれば冒頭修正は成功

## 展開判断
- [ ] 年中もの①〜⑤で **2〜3本** 冒頭の崖が直ったことを確認した
- [ ] 確認できたら季節もの（⑥〜⑩）へ展開する
