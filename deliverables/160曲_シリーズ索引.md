# 160曲ロードマップ｜シリーズ索引

全16シリーズ×10曲＝160曲。**正本は各シリーズの `series_◯◯/HANDOFF_◯◯_自動生成用.md` の16ファイルだけ**です。
中身を丸ごと自動生成チャットに貼れば①から9点セットを生成できます（タイトル・物語・Suno・画像5枚・固定コメントを全曲収録済み）。
詳細な設計思想・制作順序は `160曲ロードマップ.md` を参照。

## 運用ルール（トークン節約のため・2026-08-30整理）
- **通常はこのインデックスだけを読む。** 特定シリーズの曲を扱う時だけ、該当する `series_◯◯/` のファイルを開く。
- 「全160曲まとめてSunoに貼りたい」「タイトル一覧を見たい」等、**一時的にまとめて見たい時だけ** `scripts/regenerate_views.py` でその場で生成する（下記）。生成物は常設せず、使い終わったら消してよい。
- 以前存在した `HANDOFF_全16シリーズ/` フォルダと `全160曲_Sunoプロンプト完全版.md` / `全160曲_タイトル概要タグ一覧.md` は、**正本の完全な複製・派生だったため削除済み**（4900行超の重複を解消）。同じ内容を2箇所に置かない方針に統一。

```bash
# 全曲のSunoプロンプトだけをまとめて見る/使う
python3 deliverables/scripts/regenerate_views.py suno > /tmp/全曲_suno.md

# 全曲のタイトル・概要・タグをまとめて見る
python3 deliverables/scripts/regenerate_views.py titles > /tmp/全曲_タイトル一覧.md
```

## 共通ルール（全シリーズ横断）
- 0秒フル音量・シームレスループ・no vocals
- 看板ランタンは後付けPNG合成（生成に含めない・全シリーズ共通の識別アンカー）
- 静＝ピーク禁止（restrained）／動＝ピーク歓迎（他シリーズと逆転ルール）
- 人物なし。動シリーズの「戦い」は環境描写のみで語る（例外：龍神の逆鱗は非人間の神格を部分的に許可）
- 妖刀奇譚のみ色調が例外（深紫×黒。ランタンの琥珀灯りだけは統一を維持）
