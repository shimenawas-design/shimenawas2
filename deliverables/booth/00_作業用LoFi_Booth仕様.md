軸：**配信者・動画制作者・リスナー向けのロイヤリティフリー「作業用」素材/アルバム**。音楽図書館ブランド直結。
狙い：YouTube（リーチ）→ Booth（収益化）のクロス動線。

## 1. 曲調スペック（作業用ループ素材の最適解）
YouTubeの"掴み重視"と分けて考える。**作業用は「何時間流しても疲れない没入」が命。**

| 項目 | 指定 |
|---|---|
| ジャンル | 幻想和風LoFi × シネマティック（据え置き） |
| BPM | 60〜75（アルバム内で統一。作業/集中を妨げない） |
| メロディ | **控えめ・反復に耐える**。主張しすぎない（掴み過多はNG＝作業で飽きる） |
| 起伏 | ゆるやか。強い起承転結を避け、長時間ループで自然に |
| 楽器 | 篠笛・琴・尺八・琵琶・鈴・木魚＋LoFi Beat・Warm Bass・Warm Analog Vinyl |
| シネマティック層 | 弦パッド・ドローン・広いリバーブを**薄く**（前に出さない＝restrained） |
| 冒頭 | 0秒からフル音量（無音/フェードイン禁止）＝**ループ継ぎ目が自然になる** |
| ボーカル | なし |
| ムード統一 | 1商品＝1テーマ（例：夜の書庫／神社の夜／温泉宿）。一聴で用途が分かる |

## 2. ループ設計（Boothで最重要）
- **シームレスループ必須**：頭とお尻が繋がる。**フェードイン/アウトを付けない**。
- ループ点をクリーンに（小節の頭で切る／無音を挟まない）。
- ラウドネス統一（配信で使いやすいよう -14 LUFS 目安）。音量は他BGMと同等。

## 3. 尺・ファイル構成（1トラックあたり同梱）
- **ループ版**：1〜3分（シームレス）→ ユーザーが好きな長さに回せる
- **作業用ロング版**：30分 or 60分（ループを組んだ完成版）
- **アルバム版（ノンループ）**：試聴・リスナー鑑賞用（軽い起伏あり）
- **形式**：WAV（48kHz/24bit 推奨）＋ MP3（320kbps）の両方
- （余力があれば）ステム or ドラムレス版

## 8. 作り直し方針（まとめ）
- 曲調は幻想和風LoFi×シネマティックのまま、**「作業用ループ素材」に最適化**：
