# ③ 年間公開スケジュール表

**原則**
- 季節ものは旬の**3〜4週間前**に公開（アルゴリズムに関連付けさせる助走期間）。
- 谷間は**年中もの（時間帯・天候）①〜⑤**で埋める。
- **公開は1本ずつ**。まとめて出さない。1本ごとに維持率グラフ冒頭（垂直落下していないか）を確認。
- まず年中もの①〜⑤で2〜3本、冒頭の崖が直ったことを確認 → 季節ものへ展開。
