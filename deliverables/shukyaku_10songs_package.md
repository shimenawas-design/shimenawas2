# 集客用BGM 10曲｜制作パッケージ

維持率グラフから得た結論を全曲に反映済み。
**最重要ルール：0秒からフル音量でメロディが鳴る。イントロの溜め・フェードイン・環境音スタートを禁止。**

---

## 全曲共通ルール（必ず守る）

| 項目 | 指定 |
|---|---|
| 冒頭 | 0秒目から気持ちいいメロディ。無音・環境音・フェードインは厳禁 |
| 音量 | 他のBGMチャンネルと同等の大きさ。小さくしない |
| 尺 | 1時間（集客側。2時間は幻想側の役割） |
| 音の方向 | 明るめ・輪郭のある和風ローファイ。ビートあり |
| 題材 | 実在の和の情景のみ（幻想は本命側に回す） |
| タイトル先頭 | 必ず「和風BGM」（検索の生命線） |
| サムネ書体 | 太めのゴシック体（明朝は幻想側専用） |
| サムネ | 人物なし・左に文字余白・灰青×暖色の対比 |
| 概要欄 | 幻想和風プレイリストへの導線を必ず入れる |

### Suno 冒頭指定（全曲のプロンプト末尾に付ける）
```
starts immediately with a warm melodic hook, no intro build-up, no fade-in, no silence at the start, consistent full volume from 0:00
```

### 編集時
曲の一番気持ちいい部分を0秒に配置する。頭に無音や環境音を置かない。

## 制作の進め方（おすすめ）

1. まず年中もの（①〜⑤）を優先して作る。季節に縛られず、いつ出しても検証できる
2. 1曲ごとに Suno で4〜6トラック生成 → ループで1時間に組む
3. **公開は1本ずつ**。まとめて出さない。1本ごとに維持率グラフの冒頭を確認し、崖が直ったかを見る
4. 冒頭の崖が直っていることを2〜3本で確認してから、季節ものへ展開する

## 各曲で見る指標（1点だけ）

> 維持率グラフの冒頭が、垂直落下していないか

京の茶屋は開始数秒で30%台まで落ちていた。
これが「0:00で高く、なだらかに減衰」の形になれば冒頭修正は成功。
