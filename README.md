# Gemini 画像一括ダウンローダー（Chrome拡張機能）

Google Gemini（https://gemini.google.com/ ）のチャット画面に表示されている
生成画像を、ワンクリックでまとめてローカルに保存できる Chrome 拡張機能（Manifest V3）です。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の設定ファイル（権限・対象サイト・各スクリプトの登録など） |
| `content.js` | Geminiのページに埋め込まれ、DOMから生成画像のURLを抽出するスクリプト |
| `background.js` | ポップアップと content.js の橋渡しをしつつ、実際のダウンロード処理（chrome.downloads API）を行うサービスワーカー |
| `popup.html` / `popup.css` / `popup.js` | 拡張機能アイコンをクリックしたときに表示するUIとその動作 |
| `icons/` | 拡張機能のアイコン画像（16px / 48px / 128px） |

## インストール方法（開発者モードで読み込む）

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このプロジェクトのフォルダを選択する
4. 拡張機能一覧にアイコンが追加されれば完了

## 使い方

1. Gemini（https://gemini.google.com/ ）で画像を生成する
2. 拡張機能のアイコンをクリックしてポップアップを開く
3. 「ファイル名の接頭辞」を入力する（未入力の場合は既定値 `gemini_image` が使われる）
4. 「一括ダウンロードを実行」ボタンを押す
5. まずページが自動でスクロールされ、遅延読み込みされる古い画像も読み込まれる
   （ポップアップを開いたままにしておくと、進捗メッセージがリアルタイムで表示される）
6. ページ内の生成画像が `プレフィックス_001.png`、`プレフィックス_002.png`... という
   ファイル名で、既定のダウンロードフォルダに順番に保存される

画像が1枚も見つからなかった場合や、対象がGeminiのページでない場合は、
ポップアップ内にエラーメッセージが表示されます。
また、画像の枚数が多い場合、Chromeから「複数ファイルのダウンロード」の
許可を求めるダイアログが表示されることがあります。その場合は「許可」を
選択してください（ポップアップ内にもその旨の案内を表示しています）。

## 注意事項

GeminiのHTML構造（クラス名など）はGoogle側の仕様変更で変わることがあります。
`content.js` の画像抽出処理は以下の2段構えになっており、クラス名が変わっても
ある程度動き続けるようにしています。

1. `SELECTORS` 配列に定義した「それらしいクラス名・属性」を持つ`<img>`を探す
2. 1件も見つからなかった場合は、ページ内の全`<img>`を対象に、サイズやURLの
   パターン（アイコン・アバター等の除外条件）だけで再検索する（汎用フォールバック）

それでもうまく画像を抽出できなくなった場合は、Chromeの検証ツール(F12)で
実際の`<img>`タグのクラス名を確認し、`content.js` 内の `SELECTORS` 配列に
新しいセレクタを追加してください。
