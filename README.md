| 項目 | 内容 |

## 差別化の軸

「万人向けの塗り絵」は埋もれる。**シニア特化**で尖らせる。

- 絵柄が大きい
- 線が太い
- 細部が少ない
- 塗る面積が広い

既存キャラクター（ディズニー等）は**絶対に使わない**（著作権侵害のため）。
