# 音楽図書館（@ongakutoshokan）

YouTubeチャンネル「音楽図書館」の企画・進捗ドキュメント一式。テキスト（企画書・Suno/画像プロンプト・進捗管理）のみをここに置いています。**音源(wav/mp3/flac)・動画(mp4)・画像(jpg/png)の実体ファイルはこのリポジトリには含めていません**（ローカルの `Downloads/和風BGM/` にあります）。

## まず読むもの
`260823_統合マスター_音楽図書館プロジェクト.md` — 薄いインデックス。ブランド戦略・プロジェクト全体マップ・制作進捗ステータス・共通ルール・各シリーズファイルへのリンクをまとめています。

## 構成
- `静シリーズ/` — S1〜S8（環境音主体・restrained cinematic）
- `動シリーズ/` — D1〜D8（バトル系・ピーク歓迎）
- 各シリーズフォルダ内の `_選定結果.md` — 複数テイクから最適テイクを選ぶBPM解析の結果（静・動それぞれ）
- D1〜D4の各フォルダ内 `*_画像プロンプト*.md` — Gemini生成用の完成プロンプト（不足画像分）

進捗の詳細・音源/画像の有無は統合マスターの第3章「制作進捗ステータス」を参照。
