## 3. 商品① Gemini画像 一括ダウンローダー

- **リポジトリ**：`shimenawas-design/shimenawas2`　ブランチ `claude/gemini-batch-image-downloader-626pj5`　最新コミット `8adc4c1`（origin と一致）
- **できること**：Geminiのチャット画面で拡張アイコン→接頭辞入力→ボタン1つで、表示中の生成画像を `接頭辞_001.png` 形式の連番で一括保存。チャットを自動スクロールして全画像を回収
- **成果物**
  - 拡張本体：`shimenawas2/`（`manifest.json` / `content.js` / `background.js` / `popup.*` / `icons/`）
  - 配布ZIP：`shimenawas2/dist/gemini-image-bulk-downloader-v1.0.2.zip`（＝`Note/Gemini 画像ダウンロード/商材/` にも同じものあり）
  - 導入マニュアル：`shimenawas2/docs/INSTALL_README.txt`（英数字名。配布ZIP同梱）
- **技術的な既知の注意点**（詳細は `docs/HANDOVER.md` §6）
  - Geminiの生成画像 `blob:` URL は fetch/XHR 不可（CSP）。`<img>`→canvas→`toDataURL()` で取得している
  - `chrome.downloads.download()` の `filename` は `data:` URL で無視されることがある → `onDeterminingFilename` で強制上書き
  - content script はインストール前から開いていたタブには注入されない → タブ再読み込みが必要
- **販売記事**：`Note/Gemini 画像ダウンロード/Note販売記事.md`（2026-08-30改稿）。**公開済み** `note.com/jolly_fairy6182/n/n67a46a438201`（2026-08-30に改稿版を反映）
  - 改稿方針：ベネフィット＋SEO型タイトル／GIF直下にユースケース（LINEスタンプ・塗り絵/イラスト集・BGM動画）／安全性セクションを無料ゾーンに配置（外部通信なし・対象サイト限定・ソースコード開示）／有料ライン手前にタイパ節／ROIの言及は⏳節に集約
  - 公開版の構成は良好（安全性・注意点は無料ゾーン、ROI重複なし、誇大な文言なし）。`.md` はそれに合わせて整合済み
- **残タスク**
  1. 実写デモ動画の撮影（横型16:9推奨。手順は `shimenawas2/docs/VIDEO_DEMO_HANDOVER.md`）
  2. 複数人での配布検証（うまくいかない時は F12 の `[Gemini画像DL]` ログを回収してもらう）

## 4. 商品② 一括背景透過＆自動トリミングツール

- **場所**：`Note/一括背景透過ツール/一括背景透過ツール.html`（ローカルのみ。リポジトリ未登録。配布名にリネーム済み）
- **できること**：白背景の画像を複数まとめて読み込み、ブラウザ内だけで背景透過＋自動トリミング。ZIP一括ダウンロード。画像は外部送信しない
- **仕様メモ**（2026-08-29改良後）
  - 白色許容度の初期値 18。「フチの処理」ドロップダウンで3モード：
    - `背景だけ透過（通常）`：端から連結した白だけ塗りつぶしで透過（内側のハイライト等は残る）＋フチの白かぶり除去
    - `白フチ（ダイカット枠）も消す`：連結成分ごとに穴埋めしてシルエット化し枠を除去。複数人・複数モチーフ（Zzz・音符・星など離れた要素）は全部残す。全体を囲う細い枠成分（frame ring / big arc）だけ bbox で判定して除外
    - `白フチ（ダイカット枠）を残す`：同じシルエットを切り出し、均一な白フチを付け直す（「白フチの太さ px」スライダー、初期値14）
  - 実装は距離変換（chamfer EDT）ベースの dilate / erode / fillHoles + 連結成分ラベリング。すべてブラウザ内
  - ⚠️ cut/keep は線画・イラスト向け。写真には非対応
- **販売素材（作成済み・2026-08-30／価格780円・見出しB確定）**すべて `Note/一括背景透過ツール/` 配下
  - `Note販売記事.md` / `Note入稿用_完成稿.md` … 記事（2026-08-30改稿②：ベネフィット型タイトル／ユースケース節／安全性の訴求強化／「得意なこと・苦手なこと（写真は非対応など）」を無料ゾーンに配置／タイパ節（780円の元・時間表現はマイルドに））。Note下書き `note.com/…/n9b34e520627d`（本文だけ入力済み、見出し・画像・有料ライン・ファイルは未反映）
  - `見出し画像案/` … 3案。**採用は 見出し案B_機能訴求.png**（各1280×670）
  - `記事用画像/` … 記事内 [画像挿入] 用 01〜05（1280px幅）
  - `背景透過ツール_宣伝素材/` … YouTubeショート用MP4（縦1080×1920）＋ Note用ループGIF。BGM付き42s版は `一括背景透過ツール.mp4`
