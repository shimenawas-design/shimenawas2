# 概要欄（説明文）

画像の背景（白）を透明にして、余白まで自動トリミング。
何十枚でもドラッグ＆ドロップでまとめて処理して、ZIPで一括保存できます。

▼ このツールの特長
・画像を一切アップロードしません（処理は全部ブラウザの中で完結）
・インストール不要。HTMLファイルをダブルクリックで開くだけ
・枚数制限・回数制限なしの買い切り
・PNG / JPG / WEBP 対応、出力は透過PNG
・ステッカー風の「白フチ（ダイカット枠）」を消す／整えるモードつき

▼ こんな人向け
・LINEスタンプ、絵文字、ステッカーを量産しているクリエイター
・BOOTH / minne / SUZURI などで素材・グッズを売っている方
・サムネイルやスライドで透過素材をよく使う方
