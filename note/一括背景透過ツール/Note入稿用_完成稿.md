# 【時短】画像の背景を一括で透明化！自動トリミング付き・アップロード不要のブラウザ完結ツール

イラストやロゴ、AIで生成した画像。
**「背景の白を消して透明にしたいだけ」** なのに、これが地味に面倒じゃないですか？

- Canvaの「背景リムーバ」などは**1枚ずつ**しか処理できない。何十枚もあると全部くり返し
- 無料の透過サイトは**枚数制限**・**解像度制限**、毎回サイトを開いて**アップロード**
- 未公開の素材や仕事の画像を、**外部サービス（クラウド）にアップするのがなんとなく怖い**
- 透過できても、今度は**余白のトリミング**をまた手作業…
- Photoshopは重いし、GIMPは操作が難しい

その「地味な面倒」をまるごと無くすために、ブラウザだけで動く背景透過ツールを作りました。

**画像をドラッグ＆ドロップするだけ。数秒で背景が透明になって、余白も自動でトリミング。複数枚まとめてZIPでダウンロードできます。**

👉【画像アップロード：背景透過ツール_宣伝素材/操作デモ_Note用.gif】

## 💡 こんなクリエイティブ作業をしている方へ

「大量の画像を、決まった仕様で、まとめて素材化したい」——
そんな作業をしている人ほど、このツールは効きます。

- **🎨 LINEスタンプ・絵文字・ステッカーを作っているクリエイターへ**
  40個のスタンプ用イラストを、白背景ごと透過 → 余白トリミング → 連番ZIPまで一気に。1枚ずつ透過サイトに上げる作業から解放されます。
- **🛍️ BOOTH・minne・SUZURIでグッズや素材を売っている方へ**
  商品画像の白抜き、素材集用の透過PNGづくりを、枚数無制限・買い切りで。売り物の画像を外部サイトにアップせずに処理できます。
- **🎬 YouTube・ブログで透過素材を多用する方へ**
  サムネのワンポイント素材、アイキャッチ用のイラストを、世界観を統一したまま大量にストック。
- **📊 資料・スライドにイラストを貼る方へ**
  背景の白い四角が消えるだけで、資料の見栄えは一気に変わります。

（AIイラストを「使い回せる素材」に変えたい、すべての人向けです）

## こんな「面倒」、ありませんか？

- 背景透過したい画像が、フォルダに何十枚もたまっている
- 無料サイトは「1日◯枚まで」「高画質はプレミアム」で結局進まない
- 透過した後、余白を毎回手で切り抜いている
- LINEスタンプやステッカー用のイラストに、**白いフチ（ダイカット枠）** が付いていて邪魔
- そもそも、自分の画像を知らないサーバーに送るのが不安

## このツールでできる3つのこと

### 1. ドロップするだけ。背景が数秒で透明に

白背景の画像をドラッグ＆ドロップするだけ。
数秒で背景が透過され、被写体まわりの余白も自動でトリミングされます。
**インストール不要。ブラウザでファイルを開くだけ**で使えます。

👉【画像アップロード：記事用画像/03_操作画面.png】

### 2. 複数枚を一括処理 → ZIPでまとめて保存

画像を何十枚でもまとめて読み込めます（PNG / JPG / WEBP 対応）。
処理が終わったら **「ZIPで一括ダウンロード」** ボタンひとつで、全部まとめて保存。
1枚1枚の保存作業はもう不要です。

👉【画像アップロード：記事用画像/04_一括ZIP.png】

### 3. ステッカー風の「白フチ」も、消す／整える

AIで生成したイラストにありがちな、外周の白い縁取り（ダイカット枠）。
このツールには **「フチの処理」** モードがあり、

- **白フチも消す** … 枠を除去して、イラスト本体の輪郭だけをキレイに残す
- **白フチを残す** … ガタついた枠を、均一な太さの白フチに整え直す（そのままステッカーに）

LINEスタンプ・グッズ制作をしている方には特に刺さる機能です。

👉【画像アップロード：記事用画像/05_白フチ除去.png】

## 🛡️ このツールの一番の特長：**画像を一切アップロードしません**

処理はすべて、あなたのパソコンの**ブラウザの中だけ**で完結します。
画像がどこかのサーバーに送られることはありません。ネットが切れていても動きます。

なぜ言い切れるのか——このツールの中身がシンプルだからです。

- **そもそもインストール不要。拡張機能ですらありません**
  正体は `一括背景透過ツール.html` というファイル1つ。ダブルクリックでブラウザが開き、その中で処理が完結します。パソコンに常駐したり、設定を書き換えたりは一切しません。
- **外部サーバーとの通信はゼロ**
  画像も、入力した設定値も、どこかへ送信する処理は存在しません。ブラウザを機内モード（オフライン）にしても普通に動きます。
- **ソースコードを、読める状態のまま同梱しています**
  難読化（暗号化）は一切していません。HTMLファイルをテキストエディタで開けば、何をしているか全部書いてあります。何も隠していない、ということです。

だから、**未公開のイラスト・仕事の資料・売り物の商品写真**でも安心して処理できます。
枚数無制限・回数無制限・**買い切り**（月額サブスクではありません）。

## このツールが得意なこと・苦手なこと

買ってから「思ってたのと違う」とならないよう、先に書いておきます。

**◎ 得意（キレイに抜けます）**

- 白・白に近い単色背景のイラスト、ロゴ、アイコン
- AIで生成したイラスト・ステッカー
- 背景が白い紙にスキャンした手描きイラスト

- 被写体そのものが白くて、白背景と見分けがつかないもの
- 人物写真の「髪の毛1本ずつ」レベルの繊細な切り抜き

出力は透過PNGです。動作環境は Google Chrome などのモダンブラウザを推奨します。

## 📘 導入マニュアル

### セットアップ（初回だけ・1分）

1. 展開した **`一括背景透過ツール.html`** を、分かりやすい場所（デスクトップなど）に置きます
2. そのファイルを **ダブルクリック** します → お使いのブラウザでツールが開きます

> もし「メモ帳」やコード表示で開いてしまったら、ファイルを右クリック →「プログラムから開く」→ **Google Chrome** を選んでください。
> インターネットに接続していなくても動きます。

インストールも、アカウント登録も、拡張機能の設定もありません。

### 基本の使い方（3ステップ）

1. **白背景の画像を用意**（PNG / JPG / WEBP・何十枚でもOK）
2. 画像を点線ワクの中に **ドラッグ＆ドロップ**（ワクをクリックして選択でも可）
3. 数秒で背景が透明に。**「ZIPで一括ダウンロード」** でまとめて保存

出力は透過PNG。被写体まわりの余白も自動でトリミングされます。

### 設定の説明

**白色許容度（初期値 18）**
背景の「白」をどこまで白とみなすかの調整です。

- 背景にうっすら色が残る → 数値を **上げる**（30〜50）
- 絵の淡い部分まで透けてしまった → 数値を **下げる**（8〜14）

**余白（px）**
透過後の画像の外側に足す、透明の余白の量です。

**フチの処理（3モード）**

- **背景だけ透過（通常）** … まずはこれ。基本モードです
- **白フチ（ダイカット枠）も消す** … ステッカー風の白い縁取りごと消して、絵の輪郭だけを残します
- **白フチ（ダイカット枠）を残す** … 上記の切り出し後、均一な太さの白フチを付け直します（「白フチの太さ」で調整）

> 「白フチ」モードは**線画・イラスト向け**です。写真には使えません。

設定を変えたら **「この設定で再処理」** ボタンで反映されます。

### 向いている画像 / 向いていない画像

**○ 向いている**

- 白・白に近い単色背景のイラスト、ロゴ、アイコン
- AIで生成したイラスト・ステッカー
- 背景が白い紙にスキャンした手描きイラスト

**× 向いていない**

- 写真（背景に景色や物が写っているもの）
- グラデーションや模様の背景
- 被写体そのものが白くて、白背景と見分けがつかないもの

### 困ったときは

- **ドロップしても反応しない** → ファイル形式（PNG / JPG / WEBP）を確認。Chromeで開き直す
- **絵の一部まで消える** → 「白色許容度」を下げる／「フチの処理」を"通常"に戻す
- **輪郭に白いフチが残る** → 「白色許容度」を少し上げる／「白フチも消す」モードを試す
- **Chromeで「安全でない」等の表示** → ローカルのHTMLを開いているだけなので問題ありません

それでも解決しない場合は、購入者メッセージからご連絡ください。できるだけ早く対応します。

### プライバシー

処理はすべて**あなたのパソコンのブラウザ内だけ**で完結します。
画像がサーバーに送られることは一切ありません。ネットが切れていても動きます。
