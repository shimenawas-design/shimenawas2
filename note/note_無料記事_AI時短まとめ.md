# はじめまして。AIと会話しながら時短ツールを作っています

「ピクト｜AI時短ラボ」というアカウントで、AI活用の時短ネタとツールを発信しています。

私はプログラミングができません。**AI（Claude / Gemini）に「困っていること」をそのまま伝えて、出てきたものを試して、ダメだった理由をまた伝える**——このくり返しだけで、実際に動くツールを作っています。

このアカウントで作ったもの・書いた記事を、ここに全部まとめました。**気になるところだけ拾い読み**してもらえたら十分です。

---

# ① Geminiの生成画像、1枚ずつ保存するのをやめた

Geminiで画像を作るのは一瞬なのに、保存は「右クリック→名前を付けて保存」を延々くり返す作業でした。ボタン1つで、接頭辞付きの連番ファイル名（`Route_001.png`〜）にして一括保存するChrome拡張を作りました。

LINEスタンプ・塗り絵集・動画サムネなど、**画像を量産する人**向けです。

- 🔧 ツール本体・導入手順：[Geminiの生成画像を1クリックで一括保存！自動連番リネーム付きChrome拡張機能](https://note.com/jolly_fairy6182/n/n67a46a438201)

---

# ② 画像の背景透過、Canvaで1枚ずつやるのをやめた

背景の白を消して透明PNGにするだけなのに、Canvaの背景リムーバは1枚ずつしか処理できず、何十枚もあると全部くり返しでした。ドラッグ＆ドロップで複数枚まとめて透過し、ZIPで一括保存できるブラウザツールを作りました。画像は一切アップロードしません。

- 🔧 ツール本体・導入手順：[画像の背景を一括で透明化！自動トリミング付き・アップロード不要のブラウザ完結ツール](https://note.com/jolly_fairy6182/n/n9b34e520627d)
- 📝 作るまでの話（3つの沼にハマった記録）：[非エンジニアが「画像の背景を一括で透明にするツール」を作ったら、AIイラストの"白フチ"で沼にハマった話](https://note.com/jolly_fairy6182/n/n756b29dac4fd)

# ③ Claude Codeのトークン消費を1/10にした

こちらは開発系の話です。Vibe Coding（AIに指示を出しながらアプリを作るスタイル）で使っていた「統合マスター.md」が3,407行まで肥大化し、毎回の読み込みでトークンを爆食いするようになりました。ファイルを薄いインデックス＋トピックファイルに分割して、参照コストを約1/10にした記録です。

手法をそのままチェックリスト化した無料テキストも、記事内で配布しています。

# 共通しているのは、たった1つのやり方

3つとも、作り方はまったく同じでした。

1. 「困っていること」を、そのままAI（Claude Code）に相談する
2. 出てきたものを実際に試す
3. うまくいかない理由を、また具体的にAIに伝える
4. これをくり返す

設計を自分で頑張って考える必要はありません。むしろ「困っている」という一言だけで、AI側から具体的な解決策が返ってくることのほうが多かったです。
