# 引継ぎプロンプト — 実操作デモ動画の制作（YouTube / X向け）

このファイルは、ローカルPCで「実際にGeminiと拡張機能を操作した本物の
画面収録」によるデモ動画を作るための引継ぎ資料です。ローカルのClaude
Codeセッションにそのまま貼り付けて作業を再開する、または人間が読んで
そのまま作業を進める、どちらにも使える形で書いています。

---

## これまでの経緯（前提として知っておくこと）

- 対象アプリ: `Gemini 画像 一括ダウンローダー`（Chrome拡張機能、Manifest V3）。
  Google Gemini（gemini.google.com）のチャット画面に表示された生成画像を
  ワンクリックで一括ダウンロードする。
- リポジトリ: `https://github.com/shimenawas-design/shimenawas2`
  ブランチ: `claude/gemini-batch-image-downloader-626pj5`
  最新コミット: `f679477`（このドキュメント追加時点）
- 拡張機能は**実機で動作確認済み**（バージョン`1.0.2`）。インストール手順・
  技術的な経緯は `docs/HANDOVER.md` を参照。トラブルが起きた場合は
  そちらのデバッグ手順が使える。
- 直前の作業として、**実際のGeminiを使わない「モック画面」による説明動画**
  （縦型9:16、約30秒、TikTok/Instagram/YouTube Shorts想定）をこのセッション
  内でHTML+Playwright+ffmpegで自動生成した。そのHTML原稿を
  `docs/promo/mock-demo.html` としてリポジトリに置いてある
  （ブラウザで直接開けば動きを確認できる）。ここに書かれている
  ストーリー構成・キャプション文言は今回の実写版でもそのまま流用できる:

  1. タイトル（アプリ名＋ロゴ）
  2. 課題提起: 「画像を1枚ずつ保存するのは大変…」
  3. 拡張機能のアイコンをクリック
  4. ポップアップでプレフィックスを入力 → 「ファイル名を自由に設定できる」
  5. 進捗表示（スクロール中→検索中→ダウンロード中）→
     「自動スクロールしてすべての画像を発見」
  6. 完了＋ファイル一覧表示 → 「指定した名前で連番保存」
  7. エンドカード: 「誰でも簡単、ワンクリックで保存。」＋CTA

  完成したモック動画のmp4ファイルは、このセッション内でユーザーに
  ファイル送信済み（ローカルのダウンロードフォルダ等に残っているはず）。

## 今回のゴール

上記のモックではなく、**実際にChromeへ拡張機能を読み込み、実際にGeminiで
画像を生成し、実際にポップアップを操作して本物のダウンロードが行われる
様子**を画面収録した、本物のデモ動画を作る。公開先は **YouTube と X（旧
Twitter）**。

## 重要な方向転換ポイント（前回のモックからの変更点）

前回のモックは「TikTok/Instagram/YouTube Shorts」向けの**縦型(9:16)**
だったが、今回の対象は **YouTube と X**であり、かつ**実際のデスクトップ
Chromeブラウザの画面収録**になるため、以下を推奨する。

- **推奨: 横型 (16:9, 1920x1080 または 2560x1440) で収録する。**
  デスクトップブラウザの操作画面は横長が自然で、YouTube・Xともに
  横型ネイティブ対応。無理に縦型で撮ると、ブラウザウィンドウを
  細く縮めるなど不自然な収録になりがち。
- もし後でYouTube Shorts / Xのモバイル縦型フィード向けにも展開したく
  なった場合は、**横型でマスター収録した後に、ポップアップ部分などを
  クロップ・ズームして縦型を別途書き出す**のが効率的（今回はまず
  横型マスターの完成を優先する）。
- 迷う場合はここで一旦立ち止まって判断してよい論点。ユーザーへの
  確認事項として残しておく。

## 収録の準備

1. **Googleアカウントで実際にログイン**した状態のChromeを用意する
2. Geminiで画像を**事前に2〜3枚生成**しておく（収録中に生成待ち時間が
   入ると間延びするため、生成済みのチャットを開いておくのがおすすめ。
   前回のモックに寄せるなら「夜の神社」「灯籠の参道」「霧の鳥居」の
   ような幻想的な和風テーマで統一すると絵的にまとまりが良い）
3. 拡張機能を最新版（`f679477`時点のソース、または
   `./scripts/build-zip.sh` で作ったZIP）で `chrome://extensions` に
   読み込んでおく。既に読み込み済みなら一度リロードしてバージョンが
   `1.0.2` であることを確認
4. ブラウザウィンドウを**収録解像度と同じアスペクト比**にリサイズして
   おく（例: 1920x1080で撮るならウィンドウもその比率に合わせる。
   ブックマークバーなど不要なUIは隠しておくと画面がすっきりする）
5. ポインタ（カーソル）を見やすくする設定があると尚良い（OS標準の
   「クリック時にカーソルを強調」機能や、収録ソフトのカーソル
   ハイライト機能）

### 収録ツール（OS別）

- **Windows**: `Win + G`（Xbox Game Bar、標準搭載）、または
  [OBS Studio](https://obsproject.com/)（無料、高機能。マイク音声も
  同時収録したい場合はこちらが確実）
- **Mac**: `Cmd + Shift + 5`（標準の画面収録機能）、または OBS Studio
- 収録設定の目安: **1920x1080、30fps以上**（可能なら60fps）、
  音声はナレーションを入れるなら別撮り可、キャプション（字幕）中心の
  構成なら無音でもOK

## 収録する内容（実写版シナリオ）

前回のモックのシーン構成を、実際の操作に置き換える:

1. **（任意）タイトルカード**: 動画編集ソフトで静止画/テキストとして
   後から追加してもよい。`icons/icon128.png` をロゴとして使える
2. **課題提示**: Geminiのチャット画面で、生成済みの画像が複数並んで
   いる様子を数秒映す（実際にマウスで少しスクロールしてもよい）
3. **拡張機能のアイコンをクリック**: ツールバーの拡張機能アイコンに
   実際にカーソルを合わせてクリックする
4. **ポップアップ操作**: プレフィックス欄を実際にクリックして
   キーボードで入力する様子（例: `yozakura` などテーマに合わせた文字列）
5. **「一括ダウンロードを実行」を実際にクリック**
6. **進捗表示**: 実際に表示される「スクロール中…」「ダウンロード中…」
   のメッセージが切り替わる様子をそのまま収録する
   （※ここは実際の所要時間が数秒〜十数秒かかる可能性があるので、
   間延びするようなら編集時に**倍速再生**にするとテンポが良くなる）
7. **完了とファイル確認**: 「✅ 3枚の画像をダウンロードしました！」
   の表示後、実際にOSのダウンロードフォルダ（Windowsのエクスプローラー
   / MacのFinder）を開いて、`yozakura_001.png`のようなファイルが
   ちゃんと保存されていることを見せる（← ここが「本物である」ことの
   一番の証拠になるので重要なカット）
8. **（任意）エンドカード**: アプリ名・キャッチコピー・CTA
   （前回モックの文言 `誰でも簡単、ワンクリックで保存。` を流用可）

## 編集時に足すと良い要素

- 前回モックで使ったキャプション文言（上記「これまでの経緯」参照）を、
  そのまま字幕テロップとして画面下部にオーバーレイすると、無音でも
  内容が伝わる動画になる
- 退屈な待ち時間（スクロール中〜ダウンロード中）は編集ソフトで
  1.5〜3倍速にカットすると全体のテンポが良くなる
- BGM・効果音は著作権フリー素材を使う（YouTube Audio LibraryやX投稿
  規約に沿ったもの）

## 書き出し仕様（プラットフォーム別）

| 項目 | YouTube（通常/横型） | X（旧Twitter） |
|---|---|---|
| 推奨解像度 | 1920x1080（16:9） | 1920x1080 または 1280x720（16:9） |
| コーデック | H.264 (mp4) | H.264 (mp4) |
| 長さ目安 | 30秒〜90秒程度（デモとして） | **2分20秒(140秒)以内**（無料アカウントの上限。Premiumはより長尺可） |
| ファイルサイズ | 特に制限は緩いが数百MB程度に収める | 512MB以内 |
| フレームレート | 30fps以上 | 30fps以上 |
| 音声 | 任意（ナレーション/BGM/無音いずれも可） | 任意 |

ffmpegで書き出す場合のコマンド例（収録した動画が `raw.mov` や `raw.mp4`
としてある前提。前回のモック動画制作でも同様のコマンドを使った）:

```bash
ffmpeg -i raw.mov -c:v libx264 -profile:v high -pix_fmt yuv420p \
  -r 30 -crf 18 -movflags +faststart -c:a aac -b:a 128k \
  gemini_bulk_downloader_real_demo.mp4
```
