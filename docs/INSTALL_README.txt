Gemini 画像一括ダウンローダー - かんたんインストール手順
======================================================

このZIPファイルには、Google Gemini（gemini.google.com）で生成した
画像をワンクリックでまとめて保存できるChrome拡張機能が入っています。

【手順1】ZIPファイルを展開（解凍）する
--------------------------------------------
ダウンロードした ZIP ファイルを右クリックし、
「すべて展開」（Windows）または ダブルクリック（Mac）で
フォルダを取り出してください。

★重要: 展開したフォルダは、後で消したり移動したりしないでください。
　このフォルダの中身をChromeが直接読み込んで動作するため、
　フォルダを削除すると拡張機能が使えなくなります。
　デスクトップなど、分かりやすい場所に置いておくことをおすすめします。


【手順2】Chromeの拡張機能ページを開く
--------------------------------------------
Chromeのアドレスバー（URLを入力するところ）に、次のように入力して
Enterキーを押してください。

    chrome://extensions

すると、インストール済みの拡張機能の一覧ページが開きます。


【手順3】「デベロッパーモード」をオンにする
--------------------------------------------
ページの右上あたりに「デベロッパーモード」というスイッチ（トグル）が
あります。これをクリックしてオンにしてください。
オンにすると、新しいボタンがいくつか表示されます。


【手順4】拡張機能を読み込む
--------------------------------------------
「パッケージ化されていない拡張機能を読み込む」というボタンを
クリックし、【手順1】で展開したフォルダを選択してください。
（フォルダの中に manifest.json というファイルがある、その
フォルダ自体を選びます）

一覧に「Gemini 画像一括ダウンローダー」が追加されれば完了です！


【手順5】使ってみる
--------------------------------------------
1. Chromeの拡張機能アイコン（パズルのピースのマーク）をクリックし、
   ピン留めしておくと便利です。
2. Gemini（https://gemini.google.com/）を開き、画像を生成します。
3. 拡張機能のアイコンをクリックしてポップアップを開きます。
4. 「ファイル名の接頭辞」を入力します（そのままでもOK）。
5. 「一括ダウンロードを実行」ボタンを押します。
6. 少し待つと、パソコンの「ダウンロード」フォルダに画像が
   まとめて保存されます。


よくある質問・トラブル対応
======================================================

Q. Chromeを再起動したら「デベロッパーモードの拡張機能が無効に
   なっています」という警告が出た
A. 心配ありません。警告バナーの「そのまま維持」ボタンを押せば、
   引き続き使用できます（ウイルスや危険なものではなく、Chrome
   ウェブストアを経由せずにインストールした拡張機能に対する
   標準的な注意表示です）。

Q. 「画像が見つかりませんでした」と表示される
A. 画像を生成したチャット画面を開いた状態で、もう一度お試しください。
   それでも見つからない場合は、Gemini側の画面デザインが変更されて
   いる可能性があります。

Q. Chromeから「複数ファイルのダウンロード」の許可を求められた
A. 「許可」を選択してください。これは画像を何枚も連続して保存する
   ときにChromeが表示する標準的な確認です。

Q. フォルダを移動・削除したら動かなくなった
A. 【手順4】をもう一度行い、フォルダを選び直してください。
