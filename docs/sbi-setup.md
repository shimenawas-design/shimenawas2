# SBI証券での執行設定と、20年前からの変更点

**版数**: v0.1（2026-08-10）
**対象**: 運用資金20万円・現物のみ・保有1〜2週間

---

## 1. 20年前（2006年頃）と現在で変わったこと

個別株から離れている間に、小資金トレードの前提条件が変わっています。とくに1〜4は
「20万円で個別株をやる」という選択の可否そのものに関わります。

| 項目 | 2006年頃 | 2026年現在 | 影響 |
|---|---|---|---|
| **売買手数料** | 20万円の約定で往復 約500〜2,000円 | **0円**（SBI「ゼロ革命」） | 小資金でも手数料負けしない。**最大の変化** |
| **単元株制度** | 1株・100株・1,000株が混在 | **全銘柄100株に統一**（2018年完了） | 値がさ株は単元で買えない |
| **単元未満株** | 手数料が高く実用外 | SBIの**S株は手数料0円・スプレッドなし** | 20万円でも分散が可能に |
| **NISA** | 存在しない | 新NISA（2024年〜） | **ただし短期売買には使ってはいけない**（§4参照） |
| **立会時間** | 〜15:00 | **〜15:30**（2024年11月延長） | 引け後の作業開始時刻が30分後ろ倒し |
| **受渡日** | T+3 | **T+2**（2019年〜） | 資金の回転が1日速い |
| **呼値** | 粗い | TOPIX100銘柄は細分化 | スプレッドが縮小 |
| **PTS（夜間取引）** | ほぼ無し | SBIで利用可能 | 引け後のニュースに反応できるが、**本ルールでは使わない** |

**結論**: 手数料無料化とS株の実用化により、「20万円の個別株スイング」は
2006年当時は成立しませんでしたが、現在は**執行コスト上は成立します**。

## 2. S株（単元未満株）を主軸にする理由

### 2.1 単元株では成立しない

運用資金20万円、合計許容損失5%（＝10,000円）で計算すると：

```
$ python3 tools/position_size.py -c 200000 -r 5 -e 1500 -s 1395 -u 100
発注株数 : 0 株（発注不可）
! 最小単元(100株)でもリスクが 10,500 円となり許容額 10,000 円を超過 → 見送り
```

株価1,500円の銘柄ですら、100株買うと1トレードのリスクが許容額を超えます。
単元株で運用しようとすると、以下のいずれかを強いられます。

- 株価1,000円以下の低位株に限定する → 流動性が低く、値動きが荒い銘柄に偏る
- 損切り幅を極端に浅くする → ノイズで損切りに当たり続ける
- 許容損失を引き上げる → 数回の連敗で資金が半減する
- **同時保有1銘柄・分散ゼロ** → 1銘柄の悪材料が資金の全てを直撃する

いずれも受け入れられません。

### 2.2 S株なら成立する

```
$ python3 tools/position_size.py -c 200000 -r 1.65 -e 1500 -s 1395 -t 1680 -u 1
発注株数          :  31 株
必要資金          :  46,500 円  (資金比 23.2 %)
実際のリスク額    :   3,255 円  (資金比 1.63 %)
```

1株単位で買えるため、**3銘柄への分散**と**1銘柄あたりリスク1.65%**が両立します。
さらに銘柄の株価に制約がなくなるため、売買代金の大きい大型株を素直に選べます
（＝流動性が確保でき、寄り付きのスリッページが小さい）。

### 2.3 S株の制約と、その回避策

| 制約 | 内容 | 本ルールでの扱い |
|---|---|---|
| **指値・逆指値が使えない** | 成行注文のみ | §3の「終値判定 → 翌日寄り成行」で執行。ザラ場中の急落には即応できない |
| **約定は1日3回** | 前場始値 / 後場始値 / 後場終値 | 判断は引け後に固定しているため実害なし |
| **約定価格が事前に確定しない** | 成行のため | 売買代金20億円以上の銘柄に限定してスリッページを抑制 |
| **株主優待は基本対象外** | 100株未満のため | スイングでは優待を狙わないので影響なし |

**最大の論点は逆指値が使えないこと**です。ただし本ルールは元々
「判断は終値確定後、執行は翌営業日の寄り付き」という設計（§7）なので、
S株の約定タイミングと整合します。仕事中にザラ場を見る必要がありません。

そのうえで、逆指値がないことの実質的なリスクは以下で管理します。

- **1銘柄あたりの建玉を資金の25%以内**に抑える（1銘柄の急落が全体に及ぼす影響を限定）
- **決算跨ぎを禁止**する（想定外のギャップダウンの最大要因を除去）
- 逆指値があってもギャップダウンには対応できない（逆指値は執行価格を保証しない）ため、
  この点では単元株と条件が変わらない

## 3. 執行タイミング（S株の約定ルールに合わせる）

SBIのS株は注文の受付時間帯によって約定タイミングが決まります。
本ルールでは**「前営業日の引け後に注文を出し、翌営業日の前場始値で約定」に固定**します。

| 作業 | 時刻 | 内容 |
|---|---|---|
| 判定 | 平日 15:40〜16:30 | 終値確定後にスクリーニング・保有銘柄チェック |
| 発注 | 判定直後（当日夜まで） | 翌営業日の**前場始値**で約定する時間帯に出す |
| ザラ場 | 9:00〜15:30 | **見ない** |

※ 受付時間の区切りはSBIの公式ページ（S株の取引ルール）で最新のものを確認してください。
仕様変更があった場合はこのドキュメントを更新します。

## 4. 口座区分：NISAを使ってはいけない

**スイングトレードは必ず「特定口座（源泉徴収あり）」で行ってください。**

NISA成長投資枠を使うと、以下の理由で不利になります。

1. **売却しても年間投資枠が復活しない** — 20万円で売買を繰り返すと、
   数回転で年間240万円の枠を使い切ります。翌年まで買えなくなります。
2. **損益通算ができない** — 損失が出ても他の利益と相殺できません。
3. **繰越控除ができない** — 損失を翌年以降に繰り越せません。

NISA枠は現在メインで運用されている投資信託（長期保有）に充ててください。
制度の設計思想と用途が一致します。

## 5. スクリーニング条件のSBIでの設定

`HYPER SBI 2`（無料の取引ツール）の **銘柄検索 → スクリーニング** で設定します。
条件は「Myスクリーナー」に保存できます（最大6件）。

### 設定する条件（`docs/swing-trading-rules.md` §3・§4 に対応）

| 条件 | 設定値 | 目的 |
|---|---|---|
| 売買代金（または出来高×株価） | **20億円以上** | S株の成行約定でのスリッページ抑制 |
| 時価総額 | **1,000億円以上** | 値動きの安定性、悪材料の織り込みの速さ |
| 株価 | 制限なし | S株のため上限不要 |
| 株価と25日移動平均の関係 | **株価 > 25日線** | 上昇トレンドの確認 |
| 25日線と75日線の関係 | **25日線 > 75日線** | 順行配列 |
| 25日移動平均乖離率 | **0% 〜 +8%** | 押し目圏（過熱していない） |
| RSI(14) | **40 〜 65** | 売られすぎ・買われすぎの除外 |

※ 項目名はツールのバージョンで異なる場合があります。上記に最も近い項目を選んでください。
※ ATR や決算日程はスクリーナーで絞り切れないため、候補が出た後に個別に確認します。

### 結果の受け渡し

私（Claude）は**SBIのサイトに直接アクセスできません**。ログインが必要なうえ、
この実行環境のネットワーク制限で証券・金融系サイトへの通信が遮断されています。

そのため、以下の流れで作業します。

1. あなた：HYPER SBI 2 でスクリーニング実行
2. あなた：結果を **CSVエクスポート**（スクリーニング結果、または個別銘柄の時系列データ）
3. あなた：そのCSVをこのセッションに貼り付け／アップロード
4. 私：§3・§4 の条件で機械的に絞り込み、候補と各銘柄の
   エントリー価格・損切り価格・株数・想定Rを計算して返す

株価データの時系列CSVは、HYPER SBI 2 のチャート画面 →「時系列」→「CSVエクスポート」
から取得できます。ATRや移動平均の計算にはこちらが必要です。

- [ ] SBI証券が **インターネットコース** になっているか確認（対面・IFAコースは手数料が発生）
