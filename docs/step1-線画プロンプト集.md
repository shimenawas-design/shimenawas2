# STEP 1：線画30枚の生成プロンプト集

シニア向け塗り絵本『花と動物』用。**このファイルの「プロンプト」欄を丸ごとコピーして画像生成AIに貼るだけ**で使えます。

---

## 使い方（3行）

1. 下の表から1つ選び、プロンプトをコピーして画像生成AIに貼る
2. 出てきた画像を「採否チェック」（このファイル末尾）で確認する
3. OKなら指定のファイル名で保存する（例 `01_sunflower.png`）

> **Midjourney以外を使う場合**
> 末尾の `--ar 4:5` を**消して**、代わりに `portrait orientation` を足してください。
> 例：`... no text, portrait orientation`

---

## 共通スタイル（全30枚で固定）

プロンプトに最初から埋め込んであるので、意識しなくて大丈夫です。

| 項目 | 指定 |
|---|---|
| 種類 | 白黒の線画・塗り絵ページ |
| 線 | 太くはっきり・途切れなし |
| 影・グレー | 一切なし |
| 色 | 純黒の線＋白背景のみ |
| 形 | 大きくシンプル、細部は少なめ |
| 構図 | 主役1つだけ・中央配置・余白たっぷり |
| 文字・枠線 | なし |
| 向き | 縦向き（4:5） |

## 採否チェック（1枚ごとに確認）

生成した画像を見て、**1つでも×があれば不採用**。もう一度生成してください。

| # | チェック項目 | ダメな例 |
|---|---|---|
| 1 | 線が途切れていないか | 輪郭に隙間があり、塗ると色がはみ出す |
| 2 | 塗りつぶれていないか | 黒でベタ塗りされた面がある（目の瞳以外） |
| 3 | グレー・影がないか | 薄い灰色のトーンや斜線の影が入っている |
| 4 | 線が十分太いか | 細いペン画のようで、シニアには塗りにくい |
| 5 | 形が大きいか | 絵が小さく、細かい模様が多い |
| 6 | 主役は1つ・中央か | 複数の絵が並んでいる／端に寄っている |
| 7 | 文字・枠線がないか | 英字やロゴ、外周の飾り枠が入っている |
| 8 | 既存キャラに似ていないか | ディズニー等の特定キャラに酷似 ← **必ず不採用** |

### よくある失敗と直し方

| 症状 | プロンプトへの追記 |
|---|---|
| グレーの影が入る | `flat line drawing, pure black outlines only, absolutely no gray` |
| 線が細い | `very thick bold outlines, marker pen style` |
| 細かすぎる | `minimal detail, extra simple, few lines` |
| 背景に模様が出る | `plain empty white background, no background pattern` |
| 文字が入る | `no text, no letters, no watermark` |

### 判定を手伝います

**生成した画像をこのチャットに貼っていただければ、上の8項目で私が1枚ずつ判定します。**
まとめて何枚でも大丈夫です。
