# 日本株スイングトレード 売買ルール

**版数**: v0.2（2026-08-10 更新）
**対象**: 東証上場の国内株式、**現物のみ・SBI証券のS株（単元未満株）**
**運用資金**: 200,000円
**保有期間**: 5〜10営業日（1〜2週間）

> SBI証券固有の設定・S株を選ぶ理由・20年前からの制度変更点は
> [`docs/sbi-setup.md`](sbi-setup.md) を参照。

> このドキュメントは投資助言ではありません。売買の最終判断は自己責任で行ってください。
> パラメータは検証結果とご自身の資金・生活リズムに合わせて改訂する前提で書かれています。

---

## 0. 設計思想

ルールを書く目的は3つだけです。

1. **期待値がプラスの行動を、感情を挟まずに反復する**
2. **1回の失敗で退場しない**（資金管理が最優先。手法の優劣より先）
3. **検証可能にする**（「なんとなく強そう」を排除し、後から成績を集計できる形にする）

そのため、本ルールでは以下を徹底します。

- 曖昧語（「強い」「そろそろ」「良さそう」）を使わない。すべて数値と条件式にする
- 判断のタイミングを固定する（ザラ場中の思いつきエントリーを構造的に不可能にする）
- 損切り価格をエントリー前に確定させ、書き出してから発注する

### 0.1 この運用の位置づけ（先に合意しておくこと）

運用資金20万円で本ルール通りに運用した場合、期待できる年間損益は概算で以下の通りです。

```
1トレードの期待値  +0.2R = +660円   （良好な部類）
月あたりのトレード数  2〜3回
年間トレード数       約30回
年間損益            +20,000円 前後（+10%）
```

引け後の作業に月10時間ほどかかるとして、**時間あたり170円程度**です。
金額を目的にするなら、投資信託の積立額を増やすほうが労力対効果は上です。
これは事実として先に共有しておきます。

そのうえで、20万円の個別株スイングには別の合理性があります。

1. **20年ぶりのリハビリ**：失っても生活に影響しない額で、現在の市場と制度に慣れる
2. **ルールを守る訓練**：資金量に関係なく身につく技術。将来資金を増やしたときに効く
3. **検証データの蓄積**：50トレード分の記録が、この手法が自分に合うかの判断材料になる

したがって本ルールは、**「20万円を増やすため」ではなく「手法と自分の相性を、
安全な金額で検証するため」**のものとして設計しています。
Phase 3（通算50トレード）まで到達して期待値がプラスなら、そこで初めて
資金追加を検討してください。逆に期待値がマイナスなら、20万円の損失で
「個別株スイングは自分に合わない」と分かったことになり、これも十分な成果です。

## 1. 資金管理 ★最優先

### 1.1 パラメータ

| 項目 | 記号 | 初期値 | 備考 |
|---|---|---|---|
| 運用資金 | `C` | 200,000円 | |
| **同時保有の合計リスク上限** | | **資金の5.0%** = 10,000円 | ご指定の許容損失。ここが全体の制約 |
| 同時保有銘柄数 | `N` | **3銘柄** | S株なので分散可能。1銘柄集中は禁止 |
| 1トレードあたりリスク率 | `r` | **1.65%** | `5.0% ÷ 3銘柄` |
| 1トレードあたりリスク額 | `R` | `C × r` = **3,300円** | 損切りに当たったときに失う金額 |
| 1銘柄あたり建玉の上限 | | 資金の**25%** = 50,000円 | 逆指値が使えない分、集中を避ける |
| 建玉総額の上限 | | 資金の**75%** = 150,000円 | 残り25%は現金。損切り幅7%を確保するため |
| 単元株数 | | **1株**（S株） | `position_size.py` の `-u 1` |

**「合計リスク5%」の解釈**: 3銘柄すべてが同時に損切りに当たった場合の損失が
資金の5%（10,000円）、という意味で設計しています。1トレードごとに5%を許容すると、
3銘柄同時保有時の最大損失が15%になり、数回の連敗で資金が回復不能になります。

**現金を25%残す理由**: 全額を建玉に回すと、合計リスク5%を守るために
損切り幅を平均5%まで詰めなければなりません。日々の値動きのノイズで損切りに
当たり続けます。建玉を75%に抑えることで、損切り幅7%（＝実用的な水準）が使えます。

### 1.2 ポジションサイズの計算式

```
1株あたりリスク幅  =  エントリー価格 − 損切り価格
理論株数          =  R ÷ 1株あたりリスク幅
発注株数          =  floor(理論株数 ÷ 単元株数) × 単元株数     ← 必ず切り捨て
```

**例**: `C=20万円, r=1.65%` → `R=3,300円`
エントリー 1,500円 / 損切り 1,395円（−7.0%）→ リスク幅 105円 → **発注 31株**
必要資金 46,500円（資金比23.2%）／実リスク 3,255円（資金比1.63%）

計算は `tools/position_size.py` で行う。**暗算しない。**

```bash
python3 tools/position_size.py -c 200000 -r 1.65 -e 1500 -s 1395 -t 1680 -u 1
```

`-u 1` はS株（1株単位）の指定。単元株で発注する場合は `-u 100`。

### 1.3 「リスク幅から株数を決める」ことの意味

株数を先に決めて後から損切りを置くと、値動きの荒い銘柄で損失が跳ね上がります。
**必ず「損切り価格 → リスク幅 → 株数」の順**で決めます。株数は結果であって、入力ではありません。

その結果、必要資金が**1銘柄あたりの上限50,000円を超える場合**は、株数を50,000円分まで
減らすのではなく、**その銘柄は見送り**ます。株数を無理に減らして損切りを浅くしてはいけません。

（S株は1株単位で買えるため、20年前のように「値がさ株だから買えない」という制約は
ありません。トヨタでもソニーでも1株から買えます。制約は上記の建玉上限だけです。）

### 1.4 ドローダウン・ブレーキ

| 状態 | 金額 | 対応 |
|---|---|---|
| 月間損益が `−3R` 到達 | −10,000円（資金の−5%） | その月の残りはリスク率 `r` を半分（0.8%）にする |
| 月間損益が `−6R` 到達 | −20,000円（資金の−10%） | その月は新規エントリー停止。翌月はサイズ半分で再開 |
| 月間損益が `−9R` 到達 | −30,000円（資金の−15%） | 完全休止。記録を全件レビューしてから再開 |
| 3連敗 | | 翌営業日は新規エントリーなし（クールダウン） |

このブレーキは「不調期にサイズを落とす」ためのもので、**破ると資金曲線が回復不能になります**。最も守るべきルールです。

## 2. 相場環境フィルタ（その日エントリーして良いか）

個別銘柄を見る前に、まず地合いを判定します。買い戦略は指数の方向に大きく依存します。

| TOPIX（または日経平均）の状態 | 新規買いの可否 |
|---|---|
| 25日移動平均線の上、かつ25日線が上向き | 通常サイズ（`r` = 1.65%）、同時保有3銘柄まで |
| 25日線の上、25日線が横ばい〜下向き | サイズ半分（`r` = 0.8%）、同時保有2銘柄まで |
| 25日線の下 | **新規買い停止**（保有分の管理のみ） |
| 日経VIが 30 超 | **新規停止**（値動きが想定を超える） |

追加の停止条件（イベント前後は見送る）：

- 米CPI・FOMC・米雇用統計の**前営業日**は新規エントリーなし
- 日銀金融政策決定会合の**当日**は新規エントリーなし
- SQ週の水曜〜金曜は需給が歪むためサイズ半分

## 3. 銘柄ユニバース（候補になる最低条件）

エントリー手法以前に、以下を**全て**満たさない銘柄は対象外。

| 条件 | 基準 | 理由 |
|---|---|---|
| 売買代金（20日平均） | **20億円以上** | S株は成行のみ。寄り付きのスリッページを抑えるため厚い板が必要 |
| 時価総額 | **1,000億円以上** | 悪材料の織り込みが速く、ギャップダウンの深さが限定されやすい |
| 株価 | **制限なし** | S株は1株単位。値がさ株も対象にできる |
| ATR(14) ÷ 株価 | **2.5%〜5.0%** | 2.5%未満は1〜2週間で利が乗らない。5%超は損切り幅7%の制約に収まらない |
| 決算発表日まで | **11営業日以上** | 保有期間が最大10営業日のため、跨がないにはこの余裕が要る |
| 上場からの経過 | **6ヶ月以上** | 新規上場直後は値動きの基準が定まらない |

**除外**: 監理・整理銘柄、直近に業績下方修正を出した銘柄、増資・希薄化を発表した銘柄、ストップ高翌日の寄り付き。

## 4. エントリー

セットアップは**2つだけ**に絞ります。手法を増やすと1手法あたりの試行回数が減り、検証が成立しません。

**当面は セットアップA のみを使います。** 保有期間1〜2週間という設定にはAが適合し、
また20トレード分の記録が溜まるまでは1手法に絞ったほうが検証が速く回ります。
Bは §9 の Phase 2 到達後に解禁します。

### セットアップA：押し目買い（トレンドフォロー）

上昇トレンド中の一時的な調整を拾う。勝率が比較的高く、初期はこちらを主軸に。

**条件（全て満たす）**
1. 株価 > 25日移動平均 > 75日移動平均（順行配列）
2. 直近20営業日以内に年初来高値または52週高値を更新している
3. 高値からの押し幅が **−3%〜−10%** の範囲（−10%超はトレンド崩壊の疑い）
4. 押し目の局面で出来高が減少している（＝投げではなく調整）
5. 当日、5日線または25日線にタッチして**陽線で終える**

**エントリー**: 上記が確定した日の**翌営業日の前場始値**（S株の成行注文）
→ 前日の引け後〜当日朝の受付時間内に発注する（`docs/sbi-setup.md` §3）

寄り付きが前日終値比 +3% を超えるギャップアップとなった場合は、**その日のうちに成行で手仕舞い**
（S株は事前の逆指値も条件付き注文も使えないため、約定後の対応になる）。
リスクリワードが崩れた状態で持ち続けないことが目的。

### セットアップB：ボラティリティ収縮からのブレイクアウト

値幅の圧縮後の放れを取る。勝率は低めだが1回の利益が大きい。

**条件（全て満たす）**
1. 株価 > 25日移動平均 > 75日移動平均
2. 直近10営業日の値幅（高値−安値）が、その前20営業日の平均値幅より**小さい**（収縮）
3. 当日、**直近20営業日の高値を終値で更新**
4. 当日の出来高が20日平均出来高の **1.5倍以上**

**エントリー**: 条件成立日の**翌営業日の前場始値**（Aと同じに固定する）

### 共通の禁止事項

- ザラ場中に条件を「満たしそう」と判断してのエントリー → **禁止**（判定は必ず終値確定後）
- ニュース・SNS・掲示板を見てからのエントリー → **禁止**
- 1日のエントリーは**1銘柄**まで（同時保有3銘柄・合計リスク5%の枠内でのみ）
- 同一業種で2銘柄以上を同時保有しない（半導体2銘柄は実質1ポジション。分散になっていない）

## 5. 損切り（エントリーより先に決める）

### 5.1 損切り価格の置き方

以下の2つを計算し、**エントリー価格に近いほう**（＝損切り幅が浅いほう）を採用。

```
候補1:  直近スイング安値 − 0.5 × ATR(14)
候補2:  エントリー価格 − 2.0 × ATR(14)
```

### 5.2 損切りの執行方法（S株は逆指値が使えない）

SBIのS株は成行注文のみで、**逆指値も指値も使えません**。したがって損切りは
自動執行されず、以下の手順で**自分で執行**します。

```
平日 15:40（終値確定後）
  → 保有銘柄の終値が損切り価格を下回っていないか確認
  → 下回っていたら、その場で成行の売り注文を発注
  → 翌営業日の前場始値で約定
```

これは「損切り価格に触れたら切る」ではなく「**終値ベースで損切り価格を割ったら翌日切る**」
という運用です。ザラ場中に一時的に下抜けても終値で戻していれば継続保有します
（ヒゲでの損切りを避けられる利点がある一方、急落時の損失は逆指値より大きくなり得ます）。

### 5.3 制約

- 損切り幅がエントリー価格の **7% を超える場合、そのトレードは見送り**
  （合計リスク5%・建玉75%という資金配分から逆算した上限）
- 損切り価格は**エントリー前に必ず紙／ファイルに書き出す**。約定後に決めない
- **損切り価格の引き下げは絶対禁止**。ナンピンも禁止
- 引け後のチェックを**飛ばさない**。逆指値がない以上、このチェックが唯一の防御線
- 損切りとなった銘柄への再エントリーは**最低5営業日空ける**
- チェックできない日（出張・繁忙期など）が事前に分かっている場合は、
  **その前営業日にすべて手仕舞う**。持ったまま放置しない

### 5.4 想定損失の単位「R」

`R` = 1トレードあたりリスク額（= 3,300円）。成績はすべて **R倍数**で記録します。
「+2,000円勝った」ではなく「**+0.6R**」と書く。金額で考えると、資金が増減したときに感覚がずれます。

## 6. 利確・手仕舞い

### 6.1 エントリー時に必ず確認するリスクリワード

```
目標値幅 ÷ 損切り幅  ≧  1.5     ← これを満たさないトレードは見送り
```

目標値は「直近の戻り高値」「上値の節目」「エントリー + 3ATR」のうち最も近いものを使う。

損切り幅7%・RR1.5 の場合、目標は **+10.5%** となります。ATR3〜5%の銘柄なら
1〜2週間で到達しうる水準です。届きそうにない銘柄は §3 のATR条件で弾かれます。

### 6.2 分割決済（デフォルト）

判定はすべて**終値ベース**、執行は**翌営業日の前場始値**（S株の成行）。

| タイミング | 行動 |
|---|---|
| 終値が **+1R**（エントリー +7%）以上 | **半分を利確**（31株なら15株）。残り玉の損切りを**建値**に引き上げる |
| 残り玉 | 終値が10日移動平均を下回った → 翌営業日の前場始値で手仕舞い |

株数が奇数で半分に割れない場合は**多いほう**を利確する（31株 → 16株利確・15株保有）。

### 6.3 強制手仕舞い条件

- **時間切れ**: エントリーから **10営業日**経過して +1R に届かない → 翌営業日に手仕舞い（資金効率）
- **決算前**: 決算発表の**前営業日の大引けまでに全て手仕舞い**（例外なし）
  → S株は当日13:30までの発注で後場終値に約定する時間帯がある。前日中に必ず出す
- **地合い悪化**: TOPIXが25日線を終値で明確に割り込んだ → 翌営業日の寄りで**保有銘柄を半分に減らす**
- **チェック不能日の前**: 引け後の確認ができない日が事前に分かっている → その前営業日に全て手仕舞い

### 6.4 やってはいけないこと

- 含み益が乗ってからの「もっと伸びるはず」による利確ルールの変更
- 建値まで戻ってきたときの「せめてトントンで」による損切りの後ろ倒し
- 目標到達前の利確（早すぎる利確は勝率を上げるが期待値を下げる）

## 7. 1週間の実行ルーチン

判断する時間帯を固定することで、裁量の入る余地を減らします。
S株は逆指値が使えないため、**引け後のチェックが唯一の防御線**です。ここだけは飛ばせません。

東証の立会時間は2024年11月から **15:30まで**に延長されています（20年前は15:00まで）。

### 平日 15:40〜16:10（引け後）※必須・所要20〜30分
1. **保有銘柄のチェック（先にこちら）**
   - 終値 < 損切り価格 → 売り注文を発注
   - 終値 ≥ +1R かつ未利確 → 半分の売り注文を発注、残りの損切りを建値に更新
   - 残り玉の終値 < 10日移動平均 → 売り注文を発注
   - エントリーから10営業日経過 → 売り注文を発注
   - 決算発表が翌営業日 → 売り注文を発注
2. **新規エントリーの検討（枠が空いているときだけ）**
   - 相場環境フィルタ（§2）を判定 → **エントリー可否をまず決める**
   - 可なら §3・§4 の条件でスクリーニング
   - 候補が出たら**発注内容を書き出す**：銘柄コード / 株数 / 損切り価格 / 目標価格 / 想定R
   - `position_size.py` で株数を計算してから発注（暗算しない）
3. 書き出した内容以外の注文は**出さない**

### 平日 9:00〜15:30（ザラ場）
- **見ない。** 前夜に出した成行注文が前場始値で約定するのを待つだけ
- 株価アプリの通知はオフにする（S株では即応できないので、見ても行動につながらない）

### 忙しくて引け後のチェックができない日
- 事前に分かっている場合 → **その前営業日に全て手仕舞う**
- 突発的にできなかった場合 → 翌営業日の引け後に、**遅れた分も含めて全て執行する**
  （「もう戻ったからいいか」で見送らない。ルール違反として §8 に記録する）

### 土日（週次レビュー・30分）
- トレード記録の集計（§8）
- ルール遵守率の確認
- ルール改訂が必要なら**このドキュメントを版数を上げて更新**（トレード中の思いつき改訂は禁止）

## 8. トレード記録とレビュー

`docs/trade-journal-template.csv` を複製して使用。**全トレードを例外なく記録**します。

### 記録項目

`entry_date, code, name, setup, entry_price, shares, stop_price, target_price, risk_amount, planned_rr, exit_date, exit_price, pnl_yen, pnl_r, rule_compliance, market_regime, note`

- `setup`: `A`（押し目） / `B`（ブレイクアウト）
- `pnl_r`: 損益 ÷ `risk_amount`。**この列が最も重要**
- `rule_compliance`: `Y` / `N`。破った場合は `note` に**どのルールをなぜ破ったか**を書く

### 月次で見る指標

| 指標 | 計算 | 目安 |
|---|---|---|
| 期待値 | `pnl_r` の平均 | **> +0.2R** なら継続。マイナスなら手法見直し |
| 勝率 | 勝ちトレード数 ÷ 総数 | セットアップAで45〜55%、Bで35〜45%が想定範囲 |
| ペイオフレシオ | 平均勝ちR ÷ 平均負けR | **> 1.5** |
| 最大ドローダウン | 資金曲線の最大下落率 | −10%以内 |
| **ルール遵守率** | `Y` の割合 | **> 90%**。ここが低い間は他の数値に意味がない |

**重要**: 遵守率が90%未満のときに手法を変更してはいけません。
成績が悪いのが「手法のせい」か「守れていないせい」かを切り分けられなくなります。

### 集計コマンド

```bash
python3 tools/review_journal.py my-journal.csv --from 2026-08-01 --to 2026-08-31
```

上記の全指標に加えて、セットアップ別の成績とルール違反トレードの一覧を出力します。
**週末のレビューではこのコマンドの出力を必ず見てから**、改訂の要否を判断してください。

## 9. 段階的な運用開始

20年のブランクがあるため、いきなり本サイズで始めません。
S株なら1株単位でサイズを調整できるので、この段階分けが実際に機能します。

| フェーズ | 移行条件 | リスク率 `r` | 1トレードのリスク額 | 使うセットアップ |
|---|---|---|---|---|
| **Phase 0** | ― | 0%（記録のみ） | 0円 | A |
| **Phase 1** | Phase 0 を20回分終える | **0.8%** | 1,600円 | A のみ |
| **Phase 2** | Phase 1 の実弾20トレードで 遵守率>90% かつ 期待値>0 | **1.65%** | 3,300円 | A（B解禁） |
| **Phase 3** | 通算50トレードで 期待値>+0.2R かつ 最大DD<10% | 資金追加を検討 | ― | A・B |

- **Phase 0（1〜2ヶ月）**: 過去チャートで20回分の売買を紙上で検証。
  §4の条件でエントリー日を特定し、§5・§6のルール通りに決済した場合の損益を記録する。
  20年ぶりなので、まずここで「今のルールが自分の生活リズムで回るか」を確認します。
  引け後30分の作業を平日20日続けられるかどうかが、実は最大の検証項目です。
- **Phase 1（2〜3ヶ月）**: 実弾。目的は「ルールを守る訓練」であって、損益は問わない。
  この期間の目標は**遵守率90%超**のみ。
- **Phase 2**: 本サイズ。ここで初めて期待値を評価する。

**サイズを上げる条件を先に決めておくこと。** 好調だからという理由で途中で上げない。

## 10. 禁止事項（違反したらレビュー対象）

1. **引け後のチェックを飛ばす**（S株には逆指値がない。ここが唯一の防御線）
2. 損切り価格を不利な方向に動かす
3. ナンピン買い下がり
4. 決算を跨いで保有する
5. ザラ場中の思いつきエントリー
6. SNS・掲示板・推奨情報を根拠にしたエントリー
7. ストップ高銘柄への翌日の飛び乗り
8. 同時保有4銘柄以上、または同一業種での2銘柄同時保有
9. 損失を取り返す目的での通常サイズ超のエントリー
10. **NISA口座での売買**（必ず特定口座。理由は `docs/sbi-setup.md` §4）
11. 投資信託（メイン運用）の資金に手をつける
12. トレード記録の未記入
