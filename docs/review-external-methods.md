# 外部手法のレビュー記録

外部の動画・書籍・記事で見た手法を、**その場でルールに取り込まないため**の記録簿。

`docs/swing-trading-rules.md` §7 の通り、ルール改訂は週末のレビュー時のみ、
かつ検証データに基づいて行います。良さそうに見えた手法はここに記録し、
**改訂候補**として保留したうえで、Phase のデータが揃ってから採否を決めます。

判定は次の3分類とします。

| 判定 | 意味 |
|---|---|
| **採用不可** | 前提（市場・時間軸・執行方法）が違い、本ルールに移植できない |
| **改訂候補** | 有用だが未検証。検証方法を決めたうえで保留 |
| **即時修正** | こちらの明らかな設計ミスを指摘している。すぐ直す |

## 001. 押し目買いの3ステップ（YouTube動画・2026-08-19 レビュー）

### 手法の要約

**大枠**
- トレンドフォローの押し目買いのみを狙う（下降トレンドの戻り売りは扱わない）
- トレンド転換には時間がかかる。レンジは「力を貯める」局面である

**3ステップ**

| | 内容 |
|---|---|
| ステップ1 | **1時間足**で「安値の切り上げ」→「高値の切り上げ」を**この順番で**確認する |
| ステップ2 | 高値切り上げ後に発生する**15分足の下降トレンド**にトレンドラインを引き、**ブレイクを待つ**。さらにブレイク後に**横ばい（レンジ）になること**を確認する |
| ステップ3 | その**レンジを上抜けたところ**でエントリー |

**補足として述べられていた点**
- レンジ中に安値が切り上がっていればなお良い
- ブレイク後に押し目をつけず伸びた場合は、伸びが止まった位置で追随
- リスクリワードは最低1:1、できれば1:2
- 損切りは直近安値あたり
- 対象はFX（ドル円）・ゴールド・仮想通貨・株価指数。「どれでも通用する」と説明
- 大きく下落している相場ではやらない

### 判定：**採用不可**（ただし §改訂候補001 として一部を抽出）

### 採用できない理由

1. **時間軸が合わない（決定的）**
   1時間足＋15分足はデイトレ〜数日の手法です。本ルールは日足ベースで保有5〜10営業日。
   さらに**S株はザラ場中に売買できません**（成行のみ・1日3回）。
   15分足のレンジブレイクでエントリーすることは物理的に不可能です。

2. **市場特性が違う**
   FX・ゴールド・仮想通貨は24時間市場で、日中のギャップがほぼありません。
   日本株は 9:00-11:30 / 12:30-15:30 のみで、**毎営業日オーバーナイトギャップが発生**します。
   15分足のトレンドラインは翌朝の寄り付きで頻繁に無効化されます。
   「どの分野でも通用する」という説明は、この差を考慮していません。

3. **裁量の余地が大きく、検証できない**
   動画中で「ざっくりで大丈夫」「この辺でもいいし」「厳密に必ずここというわけじゃない」
   と繰り返されています。トレンドラインの引き方とレンジの定義が主観的です。
   本ルール §0 の「曖昧語を使わない・すべて数値と条件式にする」と正面から対立します。

4. **検証データが示されていない**
   勝率・期待値・試行回数・ドローダウンの記載がありません。
   提示されるのは**選ばれた成功チャートのみ**で、動画中でも
   「結果論にはなりますが」「ここら辺で入れたらベストだったな」と述べられています。
   後からチャートを見て良いポイントを指し示すことは常に可能です。

5. **資金管理が丸ごと欠けている**
   ポジションサイズ、1トレードあたりのリスク率、連敗時の対処への言及がありません。
   本ルールで最優先に置いている §1 が存在しません。手法単体では運用できません。

6. **集客導線がある**
   LINE登録・インジケーター配布・他動画への誘導が含まれます。
   それ自体は問題ではありませんが、内容の中立性は割り引いて読む必要があります。

## 改訂候補 001：押し目の「切り返し確認」を条件に加える

### 動機

この動画には、**本ルールのセットアップAの弱点を突く指摘**が1つ含まれています。

> 押し目買いが難しいのは、押し目を狙っている時点では（下位足では）下降トレンドだから。
> 「ここで反発した、押し目だ」と思って入るとずるずる下がる。

現行のセットアップA 条件5は「**当日、5日線または25日線にタッチして陽線で終える**」です。
これは**下降が続いている最中の一時的な陽線1本**でも成立します。
まさに動画が指摘する失敗パターンに該当します。

動画のステップ2（下降の終了を確認してから入る）は、この問題への対処として筋が通っています。

### 検証する条件（日足・終値ベースに翻訳）

セットアップA の条件5を、以下の **A'** に差し替えたものを比較対象とします。

```
現行 A  条件5 : 当日、5日線または25日線にタッチして陽線で終える

改訂案 A' 条件5: 押し目局面において、当日の終値が直近3営業日の高値を上回る
          条件6: かつ、当日の安値が前日の安値を下回っていない（安値の切り上げ）
```

条件1〜4（順行配列・高値更新・押し幅−3〜−10%・出来高減少）は共通のまま変更しません。

### 想定されるトレードオフ

| | 期待される効果 | 懸念 |
|---|---|---|
| A'（切り返し確認あり） | 落下途中でのエントリーが減る | エントリーが遅れて**損切り幅が広がる**。§5.3 の上限7%を超えて見送りになる銘柄が増える。試行回数も減る |

どちらが優れているかは**事前には決められません**。実際に比較する必要があります。

### 検証方法（Phase 0 で実弾を使わずに実施可能）

Phase 0 の紙上検証で、**A と A' の両方の成立日を並行して記録**します。

1. 各銘柄について、A の条件5が成立した日と A' の条件5・6が成立した日を別々に記録
2. それぞれについて §5・§6 のルール通りに決済した場合の損益Rを算出
3. 20回分たまった時点で、期待値・勝率・平均損切り幅・成立頻度を比較

追加コストはほぼゼロです（同じチャートを見ながら記録を2列にするだけ）。

### 採否の判断基準

| 結果 | 判断 |
|---|---|
| A' の期待値が A を **+0.15R 以上**上回る | A' を採用し、v0.4 として改訂 |
| 差が ±0.15R 未満 | **現行A を維持**（条件が少ないほうが検証しやすいため） |
| A' の成立頻度が A の半分未満 | 差が出ても採用しない（試行回数が確保できず §11.3 の検証速度が落ちる） |

### 現時点のステータス

**保留（Phase 0 で検証予定）。ルールへの反映はまだ行わない。**
